📊 Sales Dashboard using Power BI
Overview

This project is an interactive Sales Dashboard developed using Microsoft Power BI. It provides a comprehensive view of sales performance by visualizing key business metrics such as total sales, profit, orders, and regional performance. The dashboard enables users to identify trends, monitor KPIs, and make data-driven business decisions.

Features
📈 Interactive sales performance dashboard
💰 Total Sales, Profit, and Quantity KPIs
🌍 Regional and State-wise sales analysis
📦 Product category and sub-category performance
📅 Monthly and yearly sales trends
🎛️ Dynamic filters and slicers for data exploration
📊 Interactive charts and visualizations
Tools & Technologies
